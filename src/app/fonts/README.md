# Typography

Clash Display Variable and Satoshi Variable, distributed by Indian Type Foundry through Fontshare.

- https://www.fontshare.com/fonts/clash-display
- https://www.fontshare.com/fonts/satoshi
- License: https://www.fontshare.com/licenses/itf-ffl

WOFF2 files are self-hosted via next/font/local. No browser requests go to Fontshare.

The shipped files are subset for the English page: basic Latin, Latin-1, general punctuation, arrows, and the asterisk operator. Full original variable fonts are preserved in `assets/fonts/`.
